Política de Privacidade

Automação de Canais · Última atualização: 18 de setembro de 2026

1. Sobre o aplicativo

O Automação de Canais é um aplicativo de uso privado e exclusivo do proprietário dos canais do YouTube nele cadastrados. Sua finalidade é automatizar a publicação de vídeos de autoria do próprio proprietário: upload de arquivos de vídeo, definição de título e descrição, gestão de fila de publicação por horário e leitura de estatísticas de desempenho dos próprios canais.

2. Dados acessados

Ao autorizar o aplicativo, são concedidas as seguintes permissões (escopos) OAuth sobre os canais do próprio proprietário:

  • youtube.upload — fazer upload de vídeos, definir título, descrição, tags, privacidade e agendamento, e (quando solicitado pelo proprietário) remover vídeos;
  • youtube.force-ssl — gerenciar os próprios vídeos (leitura e edição de metadados) e registrar comentários em nome do canal;
  • youtube.readonly — ler estatísticas de desempenho (visualizações, likes, comentários) dos próprios vídeos e informações do próprio canal.

Em nenhum caso o aplicativo acessa canais, vídeos ou dados de usuários terceiros: a autorização OAuth é concedida exclusivamente pelo dono de cada canal.

3. Como os dados são usados

  • Publicar vídeos produzidos pelo próprio proprietário, na agenda por ele configurada;
  • Registrar o resultado das publicações (identificador e URL do vídeo, data e hora);
  • Apresentar ao proprietário estatísticas dos próprios vídeos para acompanhamento;
  • Diagnosticar falhas de publicação (por exemplo, token expirado).

Não há venda, aluguel, compartilhamento ou uso publicitário de dados. O aplicativo não utiliza os dados para treinar modelos de aprendizado de máquina e não transfere dados a terceiros.

4. Onde os dados ficam

Todos os dados do aplicativo — inclusive os tokens OAuth — ficam armazenados localmente, no computador do proprietário, em pasta privada do sistema. Não há servidor central, banco de dados em nuvem, ferramentas de análise de audiência nem coleta de telemetria. Os dados não saem da máquina do proprietário, exceto pelas chamadas oficiais à API do YouTube em nome dele próprio.

5. Retenção e exclusão

Os tokens de acesso e os registros de publicação são mantidos enquanto o proprietário utilizar o sistema. Para excluir todos os dados, o proprietário pode: (a) revogar o acesso do aplicativo a cada canal em myaccount.google.com/permissions — o que invalida imediatamente os tokens daquele canal; e (b) apagar os arquivos locais do sistema (pasta do aplicativo, incluindo os arquivos de token).

6. Uso de dados da API do YouTube

Este aplicativo usa e transfere informações recebidas das APIs do Google em conformidade com a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use).
